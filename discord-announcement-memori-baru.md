## 📢 Sistem Memori Baru: Peristiwa Lampau

Halo semuanya! Cara karakter Mikazuki mengingatmu baru saja dirombak total, dan hasilnya jauh lebih baik.

**Dulu:** ringkasan dibuat per 20 pesan dan disimpan di browser-mu — ganti perangkat, ingatannya bisa beda. Chat Memories dan Global Memories (VIP) harus dijaga manual, satu per satu.

**Sekarang:** ada **Peristiwa Lampau** — satu catatan perjalanan chatmu yang Dirawat otomatis di server terus-menerus:

- 📱 Konsisten di semua perangkat
- 🔄 Selalu mutakhir, diperbarui otomatis saat chat berjalan
- ✍️ Bisa kamu edit sendiri (maks 6.000 karakter) — catatan editanmu tidak akan ditimpa
- ♻️ Reset kapan saja, karakter mulai merangkum ulang dari nol
- 👑 VIP: budget memori lebih besar + ringkasan lebih detail

Lorebook dan memori jangka panjang tetap bekerja seperti biasa. Fitur Chat Memories dan Global Memories sudah dipensiunkan — perannya kini diambil alih Peristiwa Lampau secara otomatis.
