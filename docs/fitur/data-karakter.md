# Data Karakter dan Memori

Setiap chat satu-lawan-satu punya halaman **Data Karakter** - tempat kamu melihat profil karakter, rangkuman percakapan, dan mengelola memori jangka panjang. Buka lewat tombol ikon orang di **kiri menu titik tiga** pada topbar chat (fitur ini tidak tersedia di group chat).

Halaman ini punya tiga tab: **Profil**, **Summary**, dan **Memories**.

## Profil

Tab ini hanya-baca dan menampilkan identitas karakter: deskripsi, atribut kepribadian (Nickname, Age, Nationality, Height, Weight, Likes, Dislikes), ulang tahun, dan kategori. Kalau karakter sudah kamu *recruit*, tab ini juga menampilkan ulang tahun lengkap dengan badge khusus saat hari-H tiba, plus **Bond Level** dan progres XP kamu.

Di bagian bawah ada tautan untuk membuka halaman karakter lengkapnya.

::: info Summary dibuat dari halaman chat
Rangkuman dibuat otomatis dari halaman chat setiap 20 pesan lengkap. Tab ini hanya menampilkannya - tidak ada tombol buat ulang di sini.
:::

## Summary

Berisi daftar rangkuman percakapan yang dibuat otomatis setiap **20 pesan lengkap** dari halaman chat. Rangkuman ditampilkan per batch, mis. "Pesan 1-20". Batch yang gagal dibuat akan ditandai, jadi kamu tahu bagian mana yang tidak terangkum.

## Memories

Tab ini menyimpan fakta penting tentang kamu yang dikirim ke model setiap chat. Ada dua jenis:

| Jenis | Untuk siapa | Kapasitas | Aksi yang tersedia |
| --- | --- | --- | --- |
| Chat Memories | Semua pengguna | Maks 10 item, maks 500 karakter per item | Tambah dan hapus (dengan konfirmasi singkat) |
| Global Memories | Khusus VIP | Tersimpan di server, terikat pada karakter ini | Hapus item satu per satu |

**Chat Memories** tersedia untuk semua orang. Isi fakta yang ingin karakter ingat terus - panggilan, preferensi, atau konteks penting. Menghapus item berarti fakta itu **tidak lagi dikirim ke model** pada chat berikutnya.

**Global Memories** bekerja sama dengan Chat Memories: keduanya dikirim bersamaan ke model pada setiap pesan. Tombol hapus dinonaktifkan sementara selama proses pembuatan summary sedang berjalan.

::: tip Memori berarti kontrol
Semua isi memori dikirim ke model setiap chat - itu keputusan privasi yang ada di tanganmu. Isi hanya yang nyaman kamu bagikan, dan hapus kapan pun kamu berubah pikiran.
:::

::: warning Global Memories khusus VIP
Di paket Free, tab Global Memories tampil terkunci. Men-getuknya akan mengantarmu ke halaman `/membership` untuk upgrade.
:::

Pelajari cara memori dipakai bersama riwayat chat di [Parameter Dasar](/byok/parameter-dasar).
